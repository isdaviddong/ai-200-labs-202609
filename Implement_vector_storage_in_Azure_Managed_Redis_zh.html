在 Azure Managed Redis 中實作語意搜尋

在此練習中，您將部署 Azure Managed Redis，並完成一個 Python Flask Web 應用程式，用以儲存產品嵌入與中繼資料、建立向量索引，以及使用餘弦距離執行相似度搜尋。您將新增程式碼以連線至 Microsoft Entra ID、建立索引、儲存產品向量，並從瀏覽器介面查詢相似產品。

此練習中執行的工作：

  • 下載專案起始檔案
  • 建立 Azure Managed Redis 資源
  • 將程式碼新增至起始檔案以完成應用程式
  • 執行應用程式以載入產品、儲存向量並執行相似度搜尋

此練習大約需要 30 分鐘完成。

開始之前

在本節中，您將檢閱此練習所需的必要條件。

若要完成本練習，您需要：

  • Azure 訂用帳戶。如果您尚未擁有，可以 註冊一個.
  • Visual Studio Code 安裝於其中一個 支援的平台.
  • Python 3.12 或更新版本。
  • 最新版的 Azure CLI.
  • Azure CLI redisenterprise 延伸模組 2.75.0 或更新版本。稍後的步驟會為您安裝或升級此延伸模組。

下載專案起始檔案並部署 Azure Managed Redis

  1. 開啟瀏覽器並輸入下列 URL 以下載入門檔案。檔案會儲存在您的預設下載位置。

    https://github.com/MicrosoftLearning/mslearn-azure-ai/raw/main/downloads/python/amr-vector-query-python.zip

  2. 將檔案複製或移動到您系統中要進行專案作業的位置，然後將其解壓縮到資料夾中。

  3. 啟動 Visual Studio Code (VS Code)，並選取 File > Open Folder... ，然後選擇包含專案檔案的資料夾。

  4. 開啟 azdeploy.py 部署指令碼，並變更指令碼頂端的兩個值以符合您的需求，然後儲存變更。 注意： 請勿變更指令碼中的其他任何內容。

  5. 在功能表列中選取 終端機 > 新增終端機 ，在 VS Code 中開啟終端機視窗。

  6. 執行下列命令登入您的 Azure 帳戶。依提示選取此練習要使用的 Azure 帳戶與訂用帳戶。

  7. 執行下列命令以確保您的訂用帳戶具有 Azure Managed Redis 所需的資源提供者。

  8. 執行下列命令以安裝或升級 Azure CLI 的 redisenterprise 延伸模組。必須使用 2.75.0 或更新版本，才能在資料庫上設定 Microsoft Entra ID 存取權。

  9. 在終端機中執行下列命令以啟動部署指令碼。

  10. 當指令碼執行時，輸入 1 以啟動 1. Create Azure Managed Redis resource option.

    此選項會建立資源群組（若尚不存在），然後部署 Azure Managed Redis。指令碼會等待部署完成（需時 5 到 10 分鐘），並在終端機中回報結果。讓指令碼保持執行，並繼續下一節，在部署佈建期間新增程式碼。請定期查看終端機是否出現錯誤。

    部署成功時，會顯示如下的確認訊息，並返回功能表：

新增連線至 Azure Managed Redis 的程式碼

在本節中，您將新增程式碼以建立使用 Microsoft Entra ID 驗證的 Redis 用戶端。使用 Entra ID 表示應用程式不需要處理存取金鑰。

get_client() 函式會從 REDIS_HOST 環境變數讀取 Redis 端點，並呼叫 create_from_default_azure_credential() 以建置認證提供者。此提供者使用 DefaultAzureCredential 取得 Microsoft Entra 權杖，並在背景自動重新整理權杖。

提示： 若要維持正確的程式碼縮排，請將程式碼貼齊左邊界（第 1 欄），選取所有貼上的行，然後按 Tab ，使程式碼區塊與 BEGIN / END 標記對齊。如有需要，請按 Shift+Tab 減少縮排。

  1. 找到 # BEGIN CONNECTION CODE SECTION 註解，並在其下方加入下列程式碼。請務必確認程式碼對齊正確。

    def get_client() -> redis.Redis:
    """Create a Redis client for Azure Managed Redis using Microsoft Entra ID."""
    redis_host = os.environ.get("REDIS_HOST")

    if not redis_host:
        raise ValueError("REDIS_HOST environment variable must be set")

    credential_provider = create_from_default_azure_credential(
        ("https://redis.azure.com/.default",),
    )

    return redis.Redis(
        host=redis_host,
        port=10000,
        ssl=True,
        decode_responses=False,
        credential_provider=credential_provider,
        socket_timeout=30,
        socket_connect_timeout=30,
    )

新增建立向量索引的程式碼

在本節中，您將新增程式碼以建立相似度搜尋所使用的 RediSearch 索引。

_create_vector_index() 函式會定義文字欄位以及名為 embedding的向量欄位。向量欄位使用採用餘弦距離的 HNSW 演算法，且嵌入維度為 8，與範例資料相符。

  1. 找到 # BEGIN CREATE VECTOR INDEX CODE SECTION 註解，並在其下方加入下列程式碼。請務必確認程式碼對齊正確。

    def _create_vector_index(self):
    """Create a RediSearch index for product semantic search."""
    try:
        schema = (
            TextField("name"),
            TextField("category"),
            TextField("product_id"),
            VectorField(
                "embedding",
                "HNSW",
                {
                    "TYPE": "FLOAT32",
                    "DIM": VECTOR_DIM,
                    "DISTANCE_METRIC": "COSINE",
                },
            ),
        )

        definition = IndexDefinition(
            prefix=["product:"],
            index_type=IndexType.HASH,
        )

        self.r.ft(VECTOR_INDEX_NAME).create_index(
            fields=schema,
            definition=definition,
        )
    except redis.ResponseError as e:
        if "already exists" not in str(e):
            raise Exception(f"Error creating vector index: {e}")
    except Exception as e:
        raise Exception(f"Error creating vector index: {e}")

  2. 儲存變更，並花幾分鐘檢閱程式碼。

新增儲存產品向量的程式碼

在本節中，您將新增程式碼，以在 Redis 中儲存產品嵌入與中繼資料。

store_product() 函式會將嵌入清單轉換為 float32 位元組，並使用 numpy 將嵌入與中繼資料寫入 Redis 雜湊，方法是呼叫 hset().

  1. 找到 # BEGIN STORE PRODUCT CODE SECTION 註解，並在其下方加入下列程式碼。請務必確認程式碼對齊正確。

    def store_product(
    self,
    vector_key: str,
    vector: list[float],
    metadata: dict[str, str] | None = None,
) -> tuple[bool, str]:
    """Store or update a product hash containing embedding and metadata."""
    try:
        embedding = np.array(vector, dtype=np.float32)
        data: dict[str, Any] = {"embedding": embedding.tobytes()}

        if metadata:
            for key, value in metadata.items():
                data[key] = str(value)

        result = self.r.hset(vector_key, mapping=data)
        if result > 0:
            return True, f"Product stored successfully under key '{vector_key}'"
        return True, f"Product updated successfully under key '{vector_key}'"
    except Exception as e:
        return False, f"Error storing product: {e}"

  2. 儲存變更，並花幾分鐘檢閱程式碼。

新增搜尋相似產品的程式碼

在本節中，您將新增程式碼，以針對向量索引執行 KNN 相似度搜尋。

search_similar_products() 函式會將查詢嵌入轉換為位元組、建置 RediSearch KNN 查詢，並傳回依分數排序的最接近產品相符項目。

  1. 找到 # BEGIN SEARCH SIMILAR PRODUCTS CODE SECTION 註解，並在其下方加入下列程式碼。請務必確認程式碼對齊正確。

    def search_similar_products(
    self,
    query_vector: list[float],
    top_k: int = 3,
) -> tuple[bool, list[dict[str, Any]] | str]:
    """Run a KNN vector query against product embeddings."""
    try:
        query_bytes = np.array(query_vector, dtype=np.float32).tobytes()

        knn_query = (
            Query(f"*=>[KNN {top_k} @embedding $query_vec AS score]")
            .return_fields("name", "category", "product_id", "score")
            .sort_by("score")
            .dialect(2)
        )

        results = self.r.ft(VECTOR_INDEX_NAME).search(
            knn_query,
            query_params={"query_vec": query_bytes},
        )

        if results.total == 0:
            return False, "No products found in Redis. Load sample products first."

        similarities: list[dict[str, Any]] = []
        for doc in results.docs:
            similarities.append(
                {
                    "key": doc.id,
                    "similarity": float(doc.score),
                    "product_id": doc.product_id.decode() if isinstance(doc.product_id, bytes) else doc.product_id,
                    "name": doc.name.decode() if isinstance(doc.name, bytes) else doc.name,
                    "category": doc.category.decode() if isinstance(doc.category, bytes) else doc.category,
                }
            )

        return True, similarities
    except Exception as e:
        return False, f"Error searching products: {e}"

  2. 儲存變更，並花幾分鐘檢閱程式碼。

疑難排解

如果您在完成此練習時遇到問題，請嘗試下列疑難排解步驟：

驗證 Azure Managed Redis 資源部署

  • 瀏覽至 Azure portal 並找到您的資源群組。
  • 確認 Azure Managed Redis 資源的 Provisioning State 為 Succeeded.
  • 執行部署指令碼的 Check deployment status 選項，並在執行應用程式之前確認叢集與資料庫已就緒。

解決部署失敗

  • 如果部署失敗，最常見的原因是您所選區域暫時沒有該 SKU 的容量。
  • 依照畫面上的指引結束指令碼，將指令碼頂端附近的 location 變數變更為其他區域，例如 eastus2、australiaeast 或 canadacentral，然後再次執行指令碼並選擇選項 1。
  • 失敗的資源會在下次嘗試前自動刪除。

檢查驗證與存取權

  • 執行下列命令，確認您已登入 Azure CLI： az account show.
  • 確認部署指令碼的 Create database and configure access 選項已成功完成，使您的帳戶擁有資料庫的資料存取原則。
  • 如果應用程式回報驗證錯誤，請稍候片刻再試一次，因為存取原則指派可能需要一點時間才會生效。

檢查程式碼完整性與縮排

  • 確認所有程式碼區塊皆已新增至下列檔案中的正確區段： client/vector_functions.py ，並位於適當的 BEGIN/END 註解標記之間。
  • 確認 Python 縮排一致（使用空格，而非定位字元）。
  • 請確認指定區段之外的程式碼未被意外刪除或修改。

驗證環境變數

  • 確認專案根目錄中同時存在 .env 和 .env.ps1 檔案，且其中包含 REDIS_HOST 值。
  • 執行 source .env （Bash）或 . ..env.ps1 （PowerShell），以將環境變數載入終端機工作階段。

檢查 Python 環境與相依性

  • 請確認在執行應用程式之前已啟用虛擬環境。
  • 請確認來自 client/requirements.txt 的所有套件都已透過執行 pip list.

沒有搜尋結果或產品遺失

  • 執行相似度搜尋之前，確認您已載入範例產品。
  • 選取下列項目，確認查詢產品索引鍵存在： List All Products.
  • 確認嵌入包含 8 個數值，以符合索引設定。
